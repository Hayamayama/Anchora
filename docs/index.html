Anchora

A macOS reading companion built on Skim — ask AI about a PDF without leaving it, and get the feedback loop studying actually needs.

Download for Mac View source on GitHub

Why

Reading a PDF and asking a question about it usually means two windows, or a chat tab open beside a reader you keep alt-tabbing back to. Anchora keeps them in one place, and treats reading as something that should produce a signal about whether it worked — not just a scrollbar that reached the bottom.

What it does

Ask AI about the page

Select text, drag to OCR a region, or capture an image region — the AI panel answers with citations back to the page.

Recall & Quiz

Write one sentence from memory and get told exactly what was right, wrong, and missed. Or get quizzed on the page you just read, then marked once you answer.

Review queue

Every Recall and Quiz correction comes back on a schedule — a day, then three, then a week — so what you got wrong doesn't just scroll away.

Study map & Paper map

A plan for the whole document — what order, what to focus on, what to skip — with a self-test checklist at the end that remembers what you've checked off.

Pin answers into the PDF

Any answer becomes an editable, ordinary PDF note. Anchora writes standard annotations, so other PDF apps can read them too.

Photos into the page

Bring in a photo of a handout or whiteboard — from an iPhone, a file, paste, or drag-and-drop — as a movable, resizable note on the page.

Thought inbox

⌘⇧J from anywhere in the app catches a stray thought in one line, without leaving the page you're reading.

Two reading profiles

Study for lectures and textbooks; Scientific for papers, separating direct evidence from interpretation and what remains unproven.

Install

  • macOS 14.0 or later
  • Apple Silicon (M-series)
  • Your own OpenAI API key

1Download and open

Get the latest build from the button above, unzip it, and drag Anchora.app to Applications.

2Get past the Gatekeeper warning

Anchora isn't notarized by Apple yet, so the first time you open it, macOS refuses and calls it damaged or from an unidentified developer. That's expected for a small project without a paid Apple developer account behind every release — it doesn't mean anything is wrong with the file.

Open System Settings → Privacy & Security, scroll down to the message about Anchora, click Open Anyway, and confirm. macOS only asks once per version.

If you're comfortable with Terminal, this does the same thing in one step:

xattr -dr com.apple.quarantine /Applications/Anchora.app

3Add your OpenAI API key

Open a PDF, show the AI panel, click ••• → Set OpenAI API Key…, and paste in a key from the OpenAI Platform. It's stored only in your Mac's Keychain — never in a PDF, never sent anywhere but OpenAI.

This uses your own API billing, separate from ChatGPT Plus. A ChatGPT subscription does not cover this. Anchora calls the OpenAI API directly, and usage is billed to your OpenAI Platform account — typically small for normal use, but real, and yours to watch.
